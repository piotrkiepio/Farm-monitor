# Farm Monitor OSI V3

Wersja PWA z formularzami:
- dodawanie ferm,
- dodawanie kurników z powierzchnią i liczbą sekcji,
- dodawanie cykli,
- data wstawienia i liczba wstawionych,
- wylęgarnia i standard,
- liczba zdanych oraz średnia masa przy zdaniu,
- raporty dzienne,
- leczenia i karencja,
- raport OSI,
- backup JSON.

## Publikacja
Skopiuj zawartość katalogu `www` do repozytorium GitHub Pages, do katalogu głównego.
Po publikacji otwórz adres GitHub Pages.

## Ważne
Ta wersja nadal zapisuje dane lokalnie w przeglądarce. Centralna baza Supabase jest przygotowana konfiguracyjnie, ale nie jest jeszcze podłączona do zapisu/odczytu danych.
